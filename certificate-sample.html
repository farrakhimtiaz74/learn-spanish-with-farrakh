Certificate ke hisse — har cheez ka matlab

  • Naam: wohi naam jo tum app mein set karte ho (Progress → Tumhara naam)
  • Level aur exam: kaun sa imtihan pass kiya — A1 se C1 Final Exams, DELE Mock, Listening Exam waghera
  • Score: kitne mein se kitne number
  • Tareekh: jis din pass kiya
  • Code: har certificate ka apna unique code — is mein ek checksum chhupa hai, jaali code foran pakra jata hai
  • QR code: scan karne par Verify page khulta hai aur code khud bhar kar check ho jata hai

Note: Upar wala certificate ek sample hai — asal certificate tumhein app ke andar exam pass karne par milta hai. Aur ek dafa phir saaf: ye seekhne ki kamyabi ka record hai, official DELE qualification nahi.
