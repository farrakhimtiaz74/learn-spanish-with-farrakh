# Learn Spanish with Farrakh

A personal Spanish learning app for an Urdu-speaking beginner (A1–B2) — built-in lessons, no AI, no key, no signup. Works offline; progress stays on your own device.

## Live site
https://farrakhimtiaz74.github.io/learn-spanish-with-farrakh/

## Run it
Open the live site, or open `index.html` in any browser (the same complete app is also saved as `learn-spanish-with-farrakh.html`). On Android Chrome you can install it: menu → Add to Home Screen.

## What's inside
- **LEARN** — 50 lessons (A1: 1–20, A2: 21–30, B1: 31–40, B2: 41–50) with quiz unlocks, Daily 5-Minute Lesson, Word + Phrase of the Day, Sentence Builder, Ser vs Estar Trainer, Irregular Verbs, Pakistan–Spain bridge phrases
- **PRACTICE** — 1250 flashcards in 33 categories with spaced repetition ("Due today"), Hard Words deck, Quiz Zone, Timed Quiz, Review Mistakes, Word Match, Ahorcado, A1 + A2 + B1 + B2 Final Exams with certificate cards, DELE-style Mock Exam
- **SPEAK & LISTEN** — listen buttons everywhere (es-ES), Repeat After Me, Shadowing, Listen & Type, Listening Library (20 passages), Listening Cinema, Dialogue Role-Play, speaking word-match %, Test My Mic
- **VERBS** — 20 verbs, present + past + "voy a" future tables, conjugation quiz
- **LIBRARY** — Reading Library (10 graded stories), Grammar Reference (all 50 lesson rules), Survival Phrasebook, Pakistan–Spain Bridge
- **EXAMS** — a Final Exam per level, a DELE-style Mock Exam and a Verb Grand Exam
- **LEVEL MAP** — 50 stepping stones across A1 · A2 · B1 · B2, tap a stone to jump to that lesson
- **SETTINGS & BACKUP** — meanings in English, Roman Urdu or اردو script, dark mode, weekly and daily goals, progress download/restore, download the app file itself
- **MY PROGRESS** — streak, words known, weekly graph, badges — all saved in localStorage on the device only

## Data
All lessons, words, dialogues and quizzes are pre-written data inside the single HTML file. There is no backend and no external AI service.
