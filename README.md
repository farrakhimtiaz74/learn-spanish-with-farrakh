# Learn Spanish with Farrakh

A personal Spanish learning app for a complete beginner (A1) whose first language is Urdu — built-in lessons, no AI, no key, no signup. Works offline; progress stays on your own device.

## Run it
Open `index.html` in any browser (same complete app is also saved as `learn-spanish-with-farrakh.html`).

## What's inside
- **LEARN** — 20 lessons in order (quiz unlocks the next at 4/5), Daily 5-Minute Lesson, Word + Phrase of the Day, Sentence Builder, Ser vs Estar Trainer
- **PRACTICE** — 503 flashcards in 15 categories with spaced repetition, Hard Words deck, Quiz Zone (4 types), Timed Quiz, Review Mistakes, A1 Final Exam with certificate card
- **SPEAK & LISTEN** — listen buttons on every Spanish item (es-ES), Repeat After Me, Shadowing, Listen & Type, speaking word-match %, Test My Mic
- **VERBS** — 20 verbs, present + past + "voy a" future tables, conjugation quiz
- **MY PROGRESS** — streak, words known, weekly goal + 7-day graph, badges — all saved in localStorage on the device only

## Data
All lessons, words, dialogues and quizzes are pre-written data inside the single HTML file. There is no backend and no external AI service.
