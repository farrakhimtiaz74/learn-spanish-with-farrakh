# Learn Spanish with Farrakh

A personal Spanish learning app for an Urdu-speaking beginner (A1–A2) — built-in lessons, no AI, no key, no signup. Works offline; progress stays on your own device.

## Live site
https://farrakhimtiaz74.github.io/learn-spanish-with-farrakh/

## Run it
Open the live site, or open `index.html` in any browser (the same complete app is also saved as `learn-spanish-with-farrakh.html`). On Android Chrome you can install it: menu → Add to Home Screen.

## What's inside
- **LEARN** — 30 lessons (A1: 1–20, A2: 21–30) with quiz unlocks, Daily 5-Minute Lesson, Word + Phrase of the Day, Sentence Builder, Ser vs Estar Trainer, Irregular Verbs, Pakistan–Spain bridge phrases
- **PRACTICE** — 800 flashcards in 21 categories with spaced repetition, Hard Words deck, Quiz Zone, Timed Quiz, Review Mistakes, Word Match, Ahorcado, A1 + A2 Final Exams with certificate cards
- **SPEAK & LISTEN** — listen buttons everywhere (es-ES), Repeat After Me, Shadowing, Listen & Type, Listening Library (20 passages), Dialogue Role-Play, speaking word-match %, Test My Mic
- **VERBS** — 20 verbs, present + past + "voy a" future tables, conjugation quiz
- **MY PROGRESS** — streak, words known, weekly graph, badges, progress download/restore (manual JSON backup) — all saved in localStorage on the device only

## Data
All lessons, words, dialogues and quizzes are pre-written data inside the single HTML file. There is no backend and no external AI service.
