Roadmap

Aane wale kaam — aur wo cheezein jo kabhi nahi hongi.

▶️ Agla qadam (next steps)

  • Play Store launch: the store package (.aab) is built and validated, and this website now has the privacy policy and pages a listing needs. The one thing missing is a Google Play developer account (a one-time US$25 fee). When that exists, the app can be submitted.
  • Friends Board: the app side is fully built, including an honest "board is not ready yet" message. One small setup step on the database side remains before friends can see each other's progress.
  • More real-device testing: every feature is verified in code before release, but real phones are the true test — a device-test checklist exists and new versions get checked against real screenshots.
  • Real screenshots: the placeholders on the app page will be replaced with genuine phone screenshots.

🚫 Jo kabhi nahi hoga (never)

  • Ads — kabhi nahi. No ads, no ad SDKs, no sponsored content.
  • Paid version — nahi. No paywall, no "Pro", no locked lessons.
  • Data bechna — kabhi nahi. There is nothing to sell: the app collects nothing.
  • Forced account — nahi. Sign-up stays optional, for cloud backup only.

💡 Tumhari raye

Roadmap par sab se zyada asar tumhari raye ka hota hai — jo feature chahiye ya jo cheez tang karti hai, GitHub par issue khol kar bata do.
