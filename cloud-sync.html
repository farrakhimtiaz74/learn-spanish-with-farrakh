Cloud Backup — Progress Ki Hifazat

Ikhtiyari backup: phone badal jaye to progress wapas — aur PIN hamesha sirf phone mein.

App local-first hai: tumhari progress tumhare phone mein rehti hai aur app bina account ke 100% chalta hai. Cloud backup sirf ek ikhtiyari hifazat hai — phone badlo ya kho jaye to progress wapas mil jaye.

☁️ Kya sync hota hai?

  • Lessons ki progress (kaun se lessons mukammal)
  • Seekhe hue alfaz aur SRS review ki halat
  • Scores, exam results aur Exam Retry Bank
  • XP, streak, daily quests ki halat
  • Settings — theme, text size, pasandeeda tools waghera
  • Avatar aur profile ki maloomat

🔒 Kya KABHI sync nahi hota?

  • App lock ka PIN — kabhi nahi, kisi surat nahi
  • PIN recovery code — ye bhi sirf tumhare phone mein rehta hai
  • Mic ki recordings — phone se bahar nahi jatein

Ye design jaan boojh kar aisa hai: backup tumhari progress ka hai, tumhari hifazat (PIN) ka nahi.

📱 Shuru kaise karun?

  1. App mein Progress tab kholo
  2. Cloud Backup wala hissa kholo
  3. Apne email aur password se account banao (email confirm ka jhanjhat nahi — foran ban jata hai)
  4. Pehli sync khud ho jati hai; us ke baad jab bhi online ho, progress tham tham kar backup hoti rehti hai

Do profiles hain to har profile ka apna alag cloud account ho sakta hai.

Account nahi banana? Koi baat nahi. App ki koi cheez account se band nahi hai. Sirf ye yaad rakho: bina cloud backup ya export ki hui file ke, phone kho jaye to progress bhi usi ke saath jayegi. Backup service Supabase par chalti hai; tafseel Privacy page par hai.
