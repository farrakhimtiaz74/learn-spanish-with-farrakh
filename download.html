Install in 3 steps

  1. Download the APK from the official GitHub Releases page (the button above).
  2. Open the downloaded file. If Android asks, allow "install from this source" for your browser — this is normal for apps installed outside the Play Store.
  3. Tap Install, open the app, start lesson 1. No account needed, ever.

Updating? Just install the new APK over the old one — same signing key, so your progress, streak and certificates carry over.
