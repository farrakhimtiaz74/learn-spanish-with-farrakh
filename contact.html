✉️ The way to reach us: GitHub

Questions, bug reports, wrong-translation reports, ideas — everything goes through the app's public GitHub repository. Open an issue and it will be read there:

Open a GitHub issue →

Repository: github.com/farrakhimtiaz74/learn-spanish-with-farrakh

Honest note: there is no support email

This is a small independent project, so there is no support email address and no call centre. GitHub issues are the one real contact route — if anyone else claims to offer "official support" for this app by email or message, it is not us.

Pehle ye dekho (check these first)

  • FAQ — the most common questions, answered.
  • Download page — install steps and update help.
  • Verify a certificate — check a certificate code online.
  • Privacy policy — exactly what data the app does and doesn't touch.

Writing a good issue

Three things make a problem fixable fast:

  1. Your phone model and Android version.
  2. The app version (the latest is v38 — see Changelog).
  3. What you tapped, what happened, and a screenshot if you can.
