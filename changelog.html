v31 — Safety Pack

PIN bhool jao to recovery code se lock khul sakta hai; 5 ghalat koshishon par 60 second ka lockout. Cloud sync ka full audit — PIN kabhi cloud mein nahi jata, poori progress sync hoti hai. Reminder reboot ke baad bhi khud set ho jata hai, exact time par.

Full audit: 756 aur Spanish lines ko asal recorded awaaz mili — kul 6,667 clips. Verb tables ki readings, Mystery stories, grammar drills (jawab ke baad 'poora jumla suno' button), gender words aur writing models — sab asal awaaz mein.

v34 — Content Quality

Ab tamam 1,500 flashcards ke saath example jumla + recorded awaaz hai. 6 reflexive verbs mile (llamarse, levantarse…) — kul 46 verbs. Numbers Trainer 999,999 tak, Shopping Prices mein bari qeematein. Medical/Emergency jumlay aur jokes/poetry tarjume dobara check hue.

v35 — Usability Pack

Home ke 83 tools ab 5 sections mein hain: Seekhna, Practice, Imtihan, Games, Dost aur Share. Kisi bhi tool ko long-press karo to wo ⭐ Pasandeeda ban kar sab se upar aa jayega. Font size ab 3 levels: Chhota, Normal, Bara.

v36 — Welcome & Identity

Bilkul naye users ke liye 3-step welcome setup. Certificates aur greeting par apna naam (Progress → App settings se badal sakte ho). Search ab packs ke jumlay aur grammar bhi dhoondta hai. Urdu script UI (beta) — dock aur headings اردو mein.

v37 — Publish Pack

Certificate par ab QR code bhi hai — phone se scan karo, code khud verify ho jayega. Aur yehi 'What's New' screen naya hai: har update ki khabar ab app ke andar.

v38 — Web Sync & Trust

Website bhi ab 60 lessons (C1 bhi shamil) aur 1,500 cards par aa gayi hai. C1 lessons ke liye 4 nayi photos. Ab password wala encrypted backup bhi banta hai (Progress → Backup), aur agar app kabhi band ho jaye to crash report khud save ho jati hai — Progress → 'Masla report karo' se bhej sakte ho.
